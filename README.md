Web 開發常用工具、程式碼片段與最佳實踐的整理倉庫，作為日常開發的快速取用參考。

## 狀態

> **規劃中**：工具與片段將陸續補上。

## 內容規劃

| 類別 | 說明 |
|------|------|
| 前端工具 | 常用函式、元件片段與樣式模式 |
| 後端工具 | API 設計、驗證、錯誤處理範例 |
| 最佳實踐 | 效能、可近用性（a11y）、SEO 整理 |
| 參考速查 | 常用指令、設定檔與資源連結 |

## 使用方式

- 依類別快速查找所需片段
- 每個片段附簡短說明與使用範例
- 優先收錄可直接複製使用的解決方案

## 目錄結構

```
webdev-toolkit/
├── frontend/       # 前端工具與片段
├── backend/        # 後端範例
├── best-practices/ # 最佳實踐整理
├── cheatsheets/    # 速查表
└── README.md
```
